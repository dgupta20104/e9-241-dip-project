# DIP Project

Handwritten mathematical expression recognition on the CROHME 2019 dataset.

## Structure

```
.
├── data/
│   ├── raw/          # Original datasets (CROHME), not modified
│   └── processed/    # Preprocessed data generated by scripts
├── docs/             # Proposal, reports, references
├── notebooks/        # Jupyter notebooks for exploration
├── outputs/          # Saved models, figures, logs, results
├── src/              # Source code
├── requirements.txt
└── README.md
```

## Setup

```bash
conda activate dip_project
pip install -r requirements.txt
```
